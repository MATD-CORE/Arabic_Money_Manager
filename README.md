# 💰 مدير الأموال - Money Manager

تطبيق ويب عربي متكامل لإدارة الأموال الشخصية، يدعم الحسابات المتعددة، التحويلات، الميزانيات، والتحليلات البيانية.

## ✨ المميزات
- 🏦 **حسابات متعددة**: بنكي، محفظة إلكترونية، نقد، ادخار
- 💸 **معاملة ذكية**: دخل/مصروف مع فئات مخصصة وارتباط تلقائي بالحسابات
- 🔄 **تحويلات داخلية**: تحويل بين أي حسابين مع تحديث الأرصدة فورياً
- 📊 **تحليلات تفاعلية**: رسوم بيانية للمصروفات والاتجاهات الشهرية
- 💰 **ميزانية مرنة**: ميزانية كلية + ميزانية لكل فئة مع تنبيهات تجاوز
- ⚙️ **إعدادات كاملة**: تغيير العملة، تصدير JSON، حذف آمن للبيانات
- 💾 **حفظ محلي**: جميع البيانات تُحفظ في `localStorage` تلقائياً
